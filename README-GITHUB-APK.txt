SK SUPERSTAR RACING - BUILD APK

1. Create a GitHub account at github.com if you do not already have one.
2. Create a new repository named: SK-Superstar-Racing
3. Upload all files and folders from this project to the repository.
4. Open the repository's Actions tab.
5. Open "Build SK Superstar Racing APK".
6. Press "Run workflow" (or push to main; the workflow also runs automatically).
7. Wait for the build to finish.
8. Open the completed workflow run and scroll to Artifacts.
9. Download "SK-Superstar-Racing-debug-APK".
10. Extract the downloaded artifact ZIP; inside is app-debug.apk.

This is a debug APK for testing, not a signed Play Store release.
